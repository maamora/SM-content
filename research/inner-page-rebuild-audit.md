# Authenticated-page rebuild — current-system audit

The current workspace already contains the required functional building blocks: persistent navigation, paper and graphite materials, source selection, a central post artboard, Brand behavior, separate caption editors, approval, export, and delivery. The rebuild will preserve these real components and their API contracts.

The visible mismatch with the supplied concepts comes from composition rather than missing functionality. The redesign must remove the generic dashboard signals: oversized route banners repeated on every page, a search row detached from the working area, equal-weight metric cards, and a source form competing with the product contact sheet. These are structural decisions, not details that can be repaired with isolated color or border overrides.

The rebuilt Overview will be an operational creative ledger with one adjacent next-action panel. Products and Brand will use an image-first asset library with a narrow Brand rules companion rather than parallel cards. Studio will retain the proven three-part task sequence, but its outer canvas, rails, stage frame, progress indicator, and finishing surface will be rebuilt as a single editorial composition.

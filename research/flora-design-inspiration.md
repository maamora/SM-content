# Creative canvas interaction reference

Source reviewed: [FLORA](https://flora.ai/) and its [Quickstart](https://flora.ai/academy/quickstart), accessed 2026-08-22.

## Patterns retained for STUDIO

The reference presents creative work as an ordered operating flow rather than a collection of isolated tools: **ideate**, **iterate**, then **scale**. Its central interaction model makes source material, workflow state, and output visible together, which supports a clear next action instead of hidden configuration.

STUDIO adopts the interaction principle, not the provider model or visual identity. The product continues to use its provider-free local SVG composition engine and describes output honestly as template composition. The implementation pass should therefore reinforce these product-native patterns:

1. Use visible, sequential state indicators for source, composition, approval, and delivery.
2. Keep output provenance explicit and avoid suggesting photorealistic or provider-backed generation.
3. Use motion to orient the user to state changes, especially after saving, rendering, approving, and scheduling.
4. Use shallow visual depth, tactile artboard surfaces, and real campaign reference material instead of generic 3D decoration.
5. Keep collaborative and publishing states truthful when OAuth or other integrations have not been configured.

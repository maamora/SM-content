# Authenticated-page rebuild — design findings

## Decision

The rebuild will stop treating the workspace as a generic dashboard. STUDIO is a **creative-operations instrument**: each page should foreground the one decision that advances a product source toward a reviewable post and then delivery. The supplied references remain the visual ground truth; the sources below guide information density and behavior rather than substituting their aesthetics.

| Source | Applicable finding | STUDIO consequence |
|---|---|---|
| Fuselab dashboard design guidance [1] | A default view should answer the user’s next question without context switching; controls need progressive disclosure rather than permanent clutter. | Overview will become a compact operational ledger with one dominant hand-off. Studio will hold detailed controls in task-based rails, not surface every option equally. |
| Creative Navy dashboard guidance [2] | Information density needs visible hierarchy, meaningful whitespace, and clear labels rather than similarly weighted widgets. | Reserve scale and acid lime for the current action and current state; use warm paper for records and charcoal for the active creative surface. |
| Brandfolder DAM guidance [3] | Asset systems work when source previews, organization, brand rules, controlled templates, and downstream distribution are visible as one chain. | Products/Brand will read as an image-led source library beside a concise brand-rule panel, with real upload and saved-brand behavior retained. |

## Rebuild rules

The reference design requires a **single continuous editorial canvas**, not a stack of interchangeable cards. The sidebar remains an orientation device but becomes quieter; each routed page receives an asymmetric composition with one large typographic anchor, one action spine, and one working surface. The acid-lime color is reserved for selection, readiness, and the next committed action. Charcoal panels imply active authoring; warm paper implies persistent records and viewing.

The supplied Overview reference is interpreted as a horizontal creative timeline: source, direction, post, and delivery must feel like one system, with the next hand-off always physically adjacent. The supplied Products/Brand reference becomes a contact-sheet library with a vertical Brand rules strip; product form and testing actions must remain real but are visually subordinate to the library. The supplied Studio reference remains the three-pane control room, but will share the same page anatomy, typography, spacing, and control hierarchy.

# STUDIO Inspiration Board: The Editorial Control Room

## Selected Direction

STUDIO should become an **Editorial Control Room**: a studio that feels closer to a calm creative desk than an “AI generator.” It pairs a Figma-like center of gravity for the active composition with Milanote-like visual memory and Frame.io-like visible handoff states. The goal is not more decoration. It is more confidence: a source is visible, a direction is editable, a draft is reviewable, and delivery is explicit.

| Reference | Borrow | Avoid |
| --- | --- | --- |
| [Figma](https://www.figma.com/) | One precise, context-rich work surface; editing and delivery connected in the same place. [1] | Copying the density or generic grey toolbars. |
| [Milanote](https://milanote.com/) | Visual organization where notes, images, and decisions belong together. [2] | Turning every STUDIO page into a freeform moodboard. |
| [Frame.io](https://frame.io/) | Clear asset lifecycle, review state, and specific handoff cues. [3] | Adding collaboration controls that the current backend cannot honestly support. |

## The Visual Recipe

The shell is graphite, the content area is warm paper, and acid lime appears only when the user needs a signal: selection, success, next action, or progress. The active page owns one strong editorial headline. Everything below it is quieter: panel labels, metadata, product records, and precise controls.

> **The right question is not “what can this page generate?” It is “what is the next creative decision?”**

The Studio page is the signature surface: left for source and direction, center for the composition, right for finishing and delivery. Product and asset pages behave like a curated contact sheet. Brand works like a compact desk of rules. Social and calendar act like a delivery board—not a social-network simulator. Admin uses the same grammar but changes to a darker, more operational tone.

## Three Visual Principles

| Principle | STUDIO treatment |
| --- | --- |
| **A visible creative thread** | Keep source → direction → post → approval → delivery legible across all pages. |
| **Material hierarchy over card clutter** | Use a few large, warm-paper working surfaces and quiet record rows instead of a wall of equally weighted cards. |
| **Motion communicates state** | 160–220 ms hover lift, selection, and staging transitions. No perpetual animated effects inside operational views. |

# Creative-studio reference notes

These notes capture external reference material used to refine STUDIO. The implementation should be inspired by the interaction principles, not copied pixel-for-pixel.

## Sources

1. [FLORA — Generative AI Canvas for Creative Teams](https://flora.ai/)
   - Positions the product as a creative workspace for ideation, iteration, and scale.
   - Treats reusable techniques and workflow recipes as first-class product surfaces.
   - Uses an editorial, outcome-led narrative rather than a generic feature checklist.

2. [Framer Stories — FLORA moves faster with full design control](https://www.framer.com/stories/flora/)
   - Emphasizes fluid composition, flexible layouts, rapid iteration, and a close relationship between idea and published surface.
   - Reinforces that the visual system should feel authored and adaptable instead of looking like a conventional admin dashboard.

3. [TechCrunch — Flora is building an AI-powered infinite canvas for creative professionals](https://techcrunch.com/2025/03/02/flora-is-building-an-ai-powered-infinite-canvas-for-creative-professionals/)
   - Describes the canvas as a visual interface for connecting text, image, and video operations.
   - Highlights creative control, branching exploration, and making many variations from one direction.

## Direction adopted for STUDIO

STUDIO should feel like a **quiet creative instrument**: dark, cinematic, spacious, and highly intentional. The product should prioritize a strong editorial command surface, a single clear next action, visual references with enough room to breathe, and technique-like workflows that make the real backend capabilities easier to understand.

The redesign should avoid a literal infinite-canvas clone. Instead, it should use a composed studio desk: a prominent creative brief, a visual output rail, a compact prompt/action dock, and contextual panels for brand, approvals, captions, and publishing. Motion should communicate progression between these parts without turning the application into a decorative graph.
